name: C · Red line first, then detail
requires_slides: false

Start with the big picture, then go into detail. Use these sections in this order, with the headings written in the notes' language (German names in brackets):

1. `## Summary` (`## Zusammenfassung`): about 5 sentences on what the lecture covered and its main takeaways.
2. `## Red line` (`## Roter Faden`): the lecture's topics as one flow on a single line, separated by ` → `, e.g. `Problem → Ansatz A → Grenzen von A → Ansatz B`. Follow it with a few sentences on how each step leads to the next.
3. One `##` section per topic of the red line, with the same names and in the same order. In each:
   - **Key points** (**Kernpunkte**): the essential content of the topic.
   - **Said but not on the slides** (**Gesagt, aber nicht auf den Folien**): what the lecturer added beyond the slides, all 🗣. Without slides, leave out this part, since everything comes from the transcript.
4. `## Exam-relevant` (`## Prüfungsrelevant`): what the lecturer stressed, repeated or explicitly marked as exam material, with timestamps; then likely exam questions. The questions are your own inference, so label them 💡.
5. `## Unclear in recording` (`## Unklar in der Aufnahme`).
6. `## Glossary` (`## Glossar`): the lecture's technical terms in alphabetical order, each with a one-line definition and its label.
