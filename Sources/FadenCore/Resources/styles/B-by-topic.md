Organise the notes by the lecture's real topics, in the order they were covered.

- Find the 3–6 topics the lecture actually consists of. A topic is a unit of content, not necessarily a slide heading; several slides and a spoken digression can form one topic.
- One `##` section per topic. Directly under the heading, give the slide range as a reference in italics, e.g. `*Folien 4–11*` or `*Slides 4–11*`, with the deck name if there are several decks. Without slides, give the time range from the transcript instead, e.g. `*[00:05:10]–[00:31:40]*`.
- In each section, cover the key points, the explanations and examples, and what the lecturer stressed. Use `###` subsections if a topic is large.
- After the last topic, add the "Unclear in recording" section.
